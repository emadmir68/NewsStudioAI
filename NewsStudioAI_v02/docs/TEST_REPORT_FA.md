# گزارش آزمون نسخه 0.2.1

آزمون‌های خودکار نسخه 0.2.1 با Python، FastAPI TestClient و FFmpeg در محیط لینوکس اجرا شدند. این آزمون‌ها جایگزین آزمون نصب و اجرای نسخه نهایی روی سخت‌افزار واقعی Windows 10/11 نیستند.

اجرای مجموعه آزمون: \`python -m pytest -q\` — نتیجه: 3 passed.

## آزمون‌های موفق
- کامپایل نحوی `app.py`
- بررسی نحوی JavaScript با `node --check`
- ساخت حساب مدیر و ورود
- ایجاد پروژه و ورود فایل MP4
- بارگذاری فایل موسیقی و لوگوی PNG
- ذخیره تیتر، نام/سمت، رنگ‌های برند و زیرنویس فارسی
- تشخیص سکوت با فایل آزمایشی دارای یک بازه سکوت واقعی
- تولید برش‌های پیشنهادی و اعمال آن‌ها پس از تأیید
- رندر عمودی و افقی MP4 با گرافیک، نوار متحرک و زیرنویس
- میکس موسیقی، کاهش نویز و کاهش خودکار موسیقی هنگام صحبت
- ثبت نظر و تغییر وضعیت بازبینی
- ایجاد کاربر بازبین و بررسی محدودیت دسترسی نقش‌ها
- دریافت فایل خروجی از API
- آزمون دسترسی نقش‌ها و جلوگیری از ساخت پروژه توسط بازبین
- دانلود فایل SRT از API
- کنترل سلامت آرشیو و استخراج خودکار بسته سورس در GitHub Actions

## آزمون‌های باقی‌مانده روی Windows 10/11
- اجرای `run_windows.bat` روی سیستم کاربر
- بررسی فونت و شکل‌دهی متن فارسی در نسخه نصب‌شده Pillow/FFmpeg
- سرعت Whisper روی پردازنده واقعی و مصرف RAM
- ساخت EXE با PyInstaller و Setup با Inno Setup
- دسترسی چند دستگاه به پنل در شبکه محلی
- رندر گزارش‌های طولانی و فایل‌های حجیم

## نکته
آزمون‌های موفق، عملکرد مسیرهای آزمایش‌شده را نشان می‌دهند؛ نه تأیید نهایی تمام ترکیب‌های رسانه‌ای یا سازگاری کامل با هر سخت‌افزار.
