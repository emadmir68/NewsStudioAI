# ملاحظات امنیتی

- رمز عبور با PBKDF2-HMAC-SHA256 و salt تصادفی ذخیره می‌شود.
- نشست در کوکی HttpOnly با SameSite=Strict نگهداری می‌شود.
- عملیات تغییردهنده در صورت وجود Origin، میزبان درخواست را بررسی می‌کند.
- نقش‌ها: مدیر، تدوینگر، بازبین.
- فایل‌ها در workspace محلی ذخیره می‌شوند.
- حالت شبکه فقط برای LAN مورد اعتماد است.

برای انتشار اینترنتی:
1. HTTPS و reverse proxy فعال شود.
2. فایروال و محدودیت دسترسی شبکه اعمال شود.
3. پشتیبان‌گیری و سیاست نگهداری فایل تنظیم شود.
4. ممیزی امنیتی و تست نفوذ انجام شود.
5. دسترسی‌های فایل و مجوزهای کاربران بررسی شود.

`run_network.bat` سرور توسعه است و نباید مستقیماً در اینترنت عمومی منتشر شود.
