# News Studio AI — نسخه 0.3.1

استودیوی نیمه‌خودکار تدوین اخبار با رابط فارسی و راست‌چین.

## امکانات
- ساخت و ذخیره پروژه و ورود ویدئو
- برش چندبخشی از ویدئوی اصلی
- تایم‌لاین چهارترکه مفهومی: تصویر، صدا، زیرنویس و گرافیک
- تشخیص سکوت با FFmpeg و اعمال برش پس از تأیید
- زیرنویس دستی و تشخیص گفتار فارسی با faster-whisper
- بارگذاری موسیقی و تنظیم حجم
- کاهش نویز با afftdn و نرمال‌سازی صدا
- ducking موسیقی هنگام صحبت با sidechaincompress
- تیتر، نام/سمت، لوگوی تصویری و نوار خبری متحرک
- قالب‌های خبر فوری، مصاحبه، گزارش میدانی و خبر رسمی
- خروجی MP4 عمودی 9:16، افقی 16:9 و مربعی 1:1
- ورود کاربران با نقش مدیر، تدوینگر و بازبین
- نظرات، وضعیت بازبینی و مدیریت کاربران
- اسکریپت ساخت EXE و Setup ویندوز

## نصب نسخه آماده Windows
1. فایل NewsStudioAI_Setup_0.2.1.exe را از بخش Releases مخزن GitHub دریافت و اجرا کنید.
2. برنامه در پوشه کاربر نصب می‌شود و برای اجرای نسخه آماده به نصب جداگانه Python یا FFmpeg نیاز ندارد.
3. در اولین اجرا حساب مدیر را بسازید.
4. برای نمایش پنجره دسکتاپ، Microsoft Edge WebView2 Runtime لازم است؛ در صورت نبود آن، برنامه مرورگر پیش‌فرض را باز می‌کند.
5. مدل Whisper در اولین استفاده از تشخیص گفتار فارسی دریافت می‌شود و ممکن است به اینترنت نیاز داشته باشد.

## اجرای نسخه سورس روی Windows
1. پوشه NewsStudioAI_v02 را از مخزن دریافت کنید.
2. Python 3.11 x64 را نصب کنید و گزینه Add Python to PATH را فعال کنید.
3. FFmpeg و ffprobe را نصب و پوشه bin را به PATH اضافه کنید؛ یا فایل‌های اجرایی آن‌ها را در vendor/ffmpeg/bin قرار دهید.
4. run_windows.bat را اجرا کنید.
5. مرورگر را در http://127.0.0.1:8765 باز کنید.
6. در اولین اجرا، حساب مدیر بسازید.
7. برای فعال‌سازی تشخیص گفتار فارسی، برنامه را ببندید و install_ai.bat را اجرا کنید.

## سخت‌افزار
برای 8GB RAM از Whisper CPU INT8 با مدل Tiny یا Base استفاده کنید و هم‌زمان فقط یک کار سنگین اجرا کنید. مدل Small ممکن است روی سیستم‌های کم‌حافظه کند یا ناپایدار باشد.

## ساخت EXE
روی Windows x64:
1. `build_windows.bat` را اجرا کنید.
2. خروجی در `dist\NewsStudioAI\NewsStudioAI.exe` قرار می‌گیرد.
3. نسخه دسکتاپ از WebView2 استفاده می‌کند؛ در صورت نبود آن، مرورگر پیش‌فرض باز می‌شود. برای ساخت Setup، Inno Setup را نصب و `installer\NewsStudioAI.iss` را کامپایل کنید.

ساخت EXE و Setup ویندوز در فرایند CI روی Windows x64 انجام می‌شود. بسته آماده شامل FFmpeg و ffprobe است. فایل‌های داده نسخه نصب‌شده در `%LOCALAPPDATA%\NewsStudioAI\workspace` ذخیره می‌شوند.

## دسترسی شبکه
`run_network.bat` سرور را در شبکه محلی قابل دسترسی می‌کند. این حالت فقط برای شبکه مورد اعتماد است. سرور توسعه را مستقیماً روی اینترنت عمومی منتشر نکنید. برای استفاده اینترنتی، HTTPS، reverse proxy، پشتیبان‌گیری، محدودسازی شبکه و ممیزی امنیتی لازم است.

## محدودیت‌های شفاف نسخه 0.2
- تایم‌لاین چهار ترک مفهومی دارد؛ drag-and-drop آزاد و تدوین چندکلیپی مستقل مانند Premiere/DaVinci هنوز کامل نیست.
- پیش‌نمایش گرافیک در پنجره ویدئو تقریبی است؛ خروجی نهایی با FFmpeg رندر می‌شود.
- کاهش نویز با فیلتر عمومی FFmpeg انجام می‌شود و جایگزین ابزارهای تخصصی بازیابی صدا نیست.
- پنل چندکاربره برای محیط محلی/شبکه طراحی شده؛ استقرار عمومی اینترنتی نیازمند سخت‌سازی و بررسی امنیتی جداگانه است.
- ساخت EXE/Setup به اسکریپت سپرده شده و باید روی ویندوز واقعی build و تست شود.


## دوبله هوشمند انیمیشن (نسخه آزمایشی 0.3.1)

- تحلیل فریم‌های ویدئو با مدل بینایی محلی Qwen3-VL از طریق Ollama.
- تشخیص شخصیت‌ها و صحنه‌ها، رونویسی خودکار گفتار اصلی با Whisper و تولید فیلمنامه و دیالوگ‌های محاوره‌ای فارسی.
- امکان اصلاح دستی زمان، متن، احساس و گوینده هر دیالوگ.
- بارگذاری نمونه صدای مرجع جداگانه برای هر شخصیت و تولید صدای فارسی با MOSS-TTS-Nano.
- ترکیب دیالوگ‌ها روی ویدئوی اصلی با FFmpeg؛ تصویر اصلی بدون تغییر نگه داشته می‌شود.
- موتورهای هوش مصنوعی محلی هستند و API پولی یا کلید سرویس نیاز ندارند. دانلود اولیه مدل‌ها به اینترنت نیاز دارد.
- برای هر شخصیت یک نمونه صدای تمیز حدود ۵ تا ۱۵ ثانیه بارگذاری کنید. فقط از صدایی استفاده کنید که اجازه استفاده از آن را دارید.
- برای نصب یک‌باره موتورهای رایگان، فایل static/setup_animation_ai.ps1 را در Windows PowerShell اجرا کنید.
- مدل بینایی پس از تحلیل از حافظه خارج می‌شود و موتور گفتار فقط هنگام تولید صدا راه‌اندازی می‌شود تا فشار روی سیستم‌های ۸ گیگابایتی کمتر شود.
- زمان‌بندی دیالوگ‌ها تقریبی است و باید بازبینی شود؛ هماهنگی دقیق حرکت لب در این نسخه ارائه نمی‌شود.


## تنظیمات خودکار ویژه Core i5-12500 / RAM 16 GB / Intel UHD 770

- پردازش هوش مصنوعی روی CPU با int8؛ گرافیک مجتمع Intel UHD 770 به‌عنوان GPU شتاب‌دهنده CUDA در نظر گرفته نمی‌شود.
- Faster-Whisper Small به‌عنوان گزینه پیشنهادی با حداکثر ۶ رشته پردازشی؛ برای سیستم‌های کم‌رم به‌صورت خودکار Base انتخاب می‌شود.
- تحلیل انیمیشن با ۴۸ فریم نمونه و وضوح نمونه ۸۹۶ پیکسل (در سیستم‌های کم‌رم: ۳۰ فریم و ۶۴۰ پیکسل).
- مدل Qwen3-VL 2B با بافت ۸۱۹۲ توکن و تا ۶ رشته CPU؛ موتور ساخت صدا حداکثر ۴ رشته.
- خروجی H.264 با preset veryfast، CRF 22 و حداکثر ۴ رشته رندر، برای 1080p و استفاده روی SSD.
- تشخیص ظرفیت حافظه فیزیکی در ویندوز و انتخاب حالت مناسب به صورت خودکار انجام می‌شود. جزئیات در پنل دوبله و /api/health قابل مشاهده است.
- هیچ مدل سنگین یا کارت گرافیک مستقل برای نصب اولیه اجباری نیست؛ دانلود مدل‌ها و آزمون واقعی دوبله همچنان به نصب موتورهای محلی نیاز دارد.


## حالت ایمن (شاخه آزمایشی؛ هنوز منتشر نشده)

- صفحه اصلی جدید ۵ مرحله‌ای با گزینه‌های محدود، دکمه توقف و دسترسی جداگانه به محیط پیشرفته.
- اولویت پردازشی پایین در ویندوز و حداکثر ۲ رشته برای کارهای سنگین.
- تحلیل تنها ۱۲ فریم ۵۱۲ پیکسلی، هر بار یک تصویر؛ Whisper Base.
- اگر RAM آزاد کمتر از ۵٫۵ گیگابایت باشد پردازش هوش مصنوعی آغاز نمی‌شود.
- پردازش سنگین هم‌زمان ممنوع است و درخواست لغو بین مراحل بررسی می‌شود؛ لغو فراخوانی فعال همیشه فوری نیست.
- **مدل‌های بینایی و TTS هنوز همراه EXE نیستند؛ این شاخه نسخه نهایی آفلاین نیست.** برای نسخه کاملاً داخلی باید فایل‌های مدل، موتورهای اجرایی و مجوزهای انتشار آن‌ها داخل بسته نصب قرار بگیرند و روی سیستم هدف آزمون شوند.


## موتورهای درون برنامه (در حال اعتبارسنجی بسته کامل)
- Qwen3.5 0.8B multimodal به همراه نسخه قابل حمل Ollama داخل پوشه ai/ollama نصب می‌شود؛ اجرای آن از داخل برنامه مدیریت می‌شود.
- Piper x64 و صدای فارسی Amir داخل ai/piper قرار می‌گیرند. این صدا در حال حاضر یک گوینده است؛ کلون‌کردن صدای هر شخصیت در این نسخه موجود نیست.
- رابط ساده، بدون نصب جداگانه Python و Ollama و بدون دستور PowerShell.
- بسته EXE تک‌فایلیِ سبک به‌تنهایی مدل‌ها را ندارد؛ فقط نصب‌کننده کامل آفلاین حاوی موتور و وزن مدل معتبر است.
- این نسخه تا پایان آزمون بارگذاری مدل‌های همراه، آزمایشی است.
