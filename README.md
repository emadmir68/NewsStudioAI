# News Studio AI

نسخه 0.2.0 — استودیوی نیمه‌خودکار تدوین ویدئوهای خبری با رابط فارسی و راست‌چین.

## دریافت سورس

فایل کامل پروژه شامل کد برنامه، رابط کاربری، مستندات و اسکریپت‌های ساخت ویندوز در این مخزن قرار دارد:

- `NewsStudioAI_v0.2.0_Windows_Source.zip`

## راه‌اندازی سریع در Windows

1. ZIP را استخراج کنید.
2. Python 3.11 x64 و FFmpeg/ffprobe را نصب کنید.
3. برای اجرای پنل مرورگری، `run_windows.bat` را اجرا کنید.
4. برای اجرای پنجره دسکتاپ، `run_desktop.bat` را اجرا کنید.
5. در اولین اجرا حساب مدیر بسازید.
6. برای فعال‌سازی تشخیص گفتار، `install_ai.bat` را اجرا کنید.

## ساخت نسخه اجرایی

روی Windows x64 فایل `build_windows.bat` را اجرا کنید. برای ساخت Setup از Inno Setup و فایل `installer/NewsStudioAI.iss` استفاده کنید.

## امکانات اصلی

- ورود ویدئو و برش چندبخشی
- تشخیص سکوت و پیشنهاد حذف سکوت
- تشخیص گفتار و زیرنویس فارسی با faster-whisper
- گرافیک خبری، تیتر، نام و سمت، لوگو و نوار خبری متحرک
- موسیقی پس‌زمینه، کاهش نویز و ducking
- خروجی عمودی 9:16، افقی 16:9 و مربعی 1:1
- کاربران با نقش‌های مدیر، تدوینگر و بازبین

## توجه

این نسخه MVP است. ساخت EXE و آزمون نهایی باید روی ویندوز انجام شود. سرور توسعه را مستقیماً در اینترنت عمومی منتشر نکنید؛ برای استقرار عمومی به HTTPS، reverse proxy و سخت‌سازی امنیتی نیاز است.

جزئیات نصب، امکانات، محدودیت‌ها و گزارش آزمون در فایل ZIP و مستندات داخل آن آمده است.
