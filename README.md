**نسخه انتشار: 0.3.1** — استودیوی نیمه‌خودکار تدوین خبر با رابط فارسی و راست‌چین.

## دریافت نسخه آماده Windows

از بخش [Releases](https://github.com/emadmir68/NewsStudioAI/releases/latest) نسخه آماده را دریافت کنید:

- **Setup:** نصب‌کننده ویندوز؛ شامل برنامه و FFmpeg/ffprobe
- **Portable:** نسخه قابل اجرا بدون نصب
- **Source:** بسته کامل سورس نسخه جاری

در اولین اجرا حساب مدیر را بسازید. برای نمایش پنجره دسکتاپ، Microsoft Edge WebView2 Runtime لازم است؛ در صورت نبود آن، برنامه مرورگر پیش‌فرض را باز می‌کند. مدل Whisper هنگام اولین استفاده دریافت می‌شود.

## نسخه ویژه سیستم i5-12500 و رم ۱۶ گیگ

نسخه 0.3.1 از تنظیم خودکار منابع استفاده می‌کند: Whisper Small/int8، تحلیل تصویری با ۴۸ فریم، رندر H.264 با چهار رشته CPU و اجرای نوبتی مدل بینایی و موتور صدای فارسی. جزئیات در پنل دوبله نمایش داده می‌شود. 

## امکانات

- ورود ویدئو و برش چندبخشی
- تشخیص سکوت و پیشنهاد حذف مکث‌ها با تأیید کاربر
- زیرنویس فارسی دستی و تشخیص گفتار با faster-whisper
- گرافیک خبری، تیتر، نام و سمت، لوگو و نوار خبری متحرک
- موسیقی پس‌زمینه، کاهش نویز و ducking
- خروجی MP4 عمودی 9:16، افقی 16:9 و مربعی 1:1
- نقش‌های مدیر، تدوینگر و بازبین، همراه با نظر و گردش بازبینی

## راه‌اندازی نسخه سورس

برای اجرای مستقیم سورس به Python 3.11 x64 و FFmpeg/ffprobe نیاز است. راهنمای کامل در [README فارسی پروژه](https://github.com/emadmir68/NewsStudioAI/blob/main/NewsStudioAI_v02/README_FA.md) قرار دارد.

## امنیت

برنامه برای استفاده محلی و شبکه LAN مورد اعتماد طراحی شده است. فایل `run_network.bat` را مستقیماً روی اینترنت عمومی منتشر نکنید. استقرار عمومی به HTTPS، reverse proxy، کنترل دسترسی شبکه، پشتیبان‌گیری و ممیزی امنیتی نیاز دارد.

## کنترل کیفیت

هر تغییر نسخه از آزمون‌های Python، JavaScript، احراز هویت، نقش‌ها، ورود رسانه، تشخیص سکوت، SRT و رندر سه نسبت تصویر عبور می‌کند. ساخت و آزمون Windows نیز در CI انجام می‌شود.
