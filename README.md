# News Studio AI

نسخه 0.2.0 — استودیوی نیمه‌خودکار تدوین ویدئوهای خبری با رابط فارسی و راست‌چین.

## دریافت سورس

بسته کامل پروژه شامل کد برنامه، رابط کاربری، مستندات و اسکریپت‌های ساخت ویندوز در مخزن قرار دارد. برای بازسازی آرشیو:

1. مخزن را با گزینه **Code → Download ZIP** دریافت و استخراج کنید.
2. در پوشه اصلی مخزن، PowerShell را باز کنید.
3. دستور زیر را اجرا کنید:

```powershell
powershell -ExecutionPolicy Bypass -File .\rebuild_source.ps1
```

4. فایل `NewsStudioAI_v0.2.0_Windows_Source.tar.xz` ساخته می‌شود. آن را با 7-Zip یا دستور `tar -xf` استخراج کنید.

## راه‌اندازی سریع در Windows

1. Python 3.11 x64 و FFmpeg/ffprobe را نصب کنید.
2. برای اجرای پنل مرورگری، `run_windows.bat` را اجرا کنید.
3. برای اجرای پنجره دسکتاپ، `run_desktop.bat` را اجرا کنید.
4. در اولین اجرا حساب مدیر بسازید.
5. برای فعال‌سازی تشخیص گفتار، `install_ai.bat` را اجرا کنید.

## ساخت نسخه اجرایی

روی Windows x64 فایل `build_windows.bat` را اجرا کنید. برای ساخت Setup از Inno Setup و فایل `installer/NewsStudioAI.iss` استفاده کنید.

## امکانات اصلی

- ورود ویدئو و برش چندبخشی
- تشخیص سکوت و پیشنهاد حذف سکوت
- تشخیص گفتار و زیرنویس فارسی با faster-whisper
- گرافیک خبری، تیتر، نام و سمت، لوگو و نوار خبری متحرک
- موسیقی پس‌زمینه، کاهش نویز و ducking
- خروجی عمودی 9:16، افقی 16:9 و مربعی 1:1
- کاربران با نقش‌های مدیر، تدوینگر و بازبین

## توجه

این نسخه MVP است. ساخت EXE و آزمون نهایی باید روی ویندوز انجام شود. سرور توسعه را مستقیماً در اینترنت عمومی منتشر نکنید؛ برای استقرار عمومی به HTTPS، reverse proxy و سخت‌سازی امنیتی نیاز است.

جزئیات نصب، امکانات، محدودیت‌ها و گزارش آزمون در مستندات فارسی بسته سورس آمده است.
